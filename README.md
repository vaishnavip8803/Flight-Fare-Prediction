# ✈️ Flight Fare Prediction using Machine Learning

## 📌 Project Overview

Flight Fare Prediction is a Machine Learning project that predicts airline ticket prices based on different travel-related features such as airline, source, destination, journey date, duration, and number of stops.

The main goal of this project is to build a regression model that can estimate flight prices and help customers make better travel decisions.

---

## 📌 Problem Statement

Flight ticket prices change frequently depending on various factors like airline, route, travel date, duration, and number of stops.

The objective of this project is to analyze historical flight data and develop a machine learning model that predicts flight fares accurately.

---

# 🎯 Project Objectives

- Analyze flight price patterns using Exploratory Data Analysis (EDA)
- Clean and preprocess flight data
- Perform feature engineering
- Build machine learning regression models
- Compare model performance
- Select the best-performing model for prediction
- Predict flight prices for new input data

---

# 📂 Dataset Description

The dataset contains flight booking information with various features:

| Feature | Description |
|---------|-------------|
| Airline | Name of the airline |
| Date_of_Journey | Date of travel |
| Source | Starting location |
| Destination | Final destination |
| Route | Flight route details |
| Dep_Time | Departure time |
| Arrival_Time | Arrival time |
| Duration | Total travel duration |
| Total_Stops | Number of stops |
| Additional_Info | Extra information |
| Price | Flight ticket price (Target Variable) |
